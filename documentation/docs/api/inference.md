# Permutation Inference

`PermutationManager` turns the shuffled-target runs into p-values: permutation
p-values for model performance, and edge-stability significance via the
Network-Based Statistic (NBS) or network TFCE.

See [Edge-stability significance](../methods.md#7-edge-stability-significance) for
the statistical reasoning behind controlling error at the subnetwork level.
